# cyber-security-Task-2-

Phishing Email Analyzer

## Objective
To identify basic phishing indicators in a suspicious email using Python.

## Tools Used
- Python
- Pydroid 3
- GitHub

## Description
This simple Python program checks an email for common phishing signs.

It checks:
- Sender email
- Urgent words
- Suspicious click messages
- Password requests

## How to Run
1. Open Pydroid 3.
2. Copy the Python code.
3. Run the program.
4. Enter the sender email.
5. Enter the email message.
6. Check the analysis report.

## Sample Input

Sender:
`unknown@gmail.com`

Message:
`Urgent! Click here to verify your password`

## Sample Output

```text
--- Report ---
Sender email checked
Warning: Urgent words found
Warning: Suspicious link/message
Warning: Password request found

Analysis completed.
